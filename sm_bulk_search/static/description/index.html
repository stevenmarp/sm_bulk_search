Feature Details

How It Works

Type, Comma, Type, Enter

There is nothing to configure and nothing to turn on.
01

Open Any List

Quotations, requests for quotation, contacts, anything.

02

Type The Values

Separated by commas. Extra spaces do not matter.

03

Pick The Field

The usual proposals: search for it in the name, the reference, the customer.

04

One List

Every record matching any of the values.

Worth Knowing

The values become ordinary search facets, so they can be saved as a favourite, taken off one by one, or combined with any other filter.

Only text is split: names, references, customers, vendors, tags. A number or a date typed with a comma in it is left alone, because a comma there means something else.

A comma always separates. A value that holds one, a company called Delta, Inc. for instance, is read as two.

The same value typed twice is kept once.
